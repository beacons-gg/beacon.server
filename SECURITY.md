# Security

Report a security issue in private. Never open a public issue or pull request for one.

## Report an issue

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Only you and the maintainers see the report.

If you can't use GitHub, email `security@beacons.gg`. Send reports about the hosted service at
beacons.gg to the same address.

A useful report names:

- the release or commit you tested;
- the steps that reproduce the issue;
- what an attacker gains, such as reading another player's data or writing as the server.

## What happens next

We acknowledge a report within 3 business days. We keep you informed while we confirm the issue and
fix it. The fix ships in a release.

## Supported versions

Only the latest release gets security fixes. Check the issue against the latest release before you
report the issue.
